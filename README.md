## Security / 安全提醒

PolyPay will never ask for your private key or seed phrase. Never share either one with anyone claiming to represent PolyPay. Verify links and announcements against this repository, the [official website](https://polypay.ai/), or the official accounts listed above.

PolyPay 绝不会索要你的私钥或助记词。请勿向任何自称 PolyPay 工作人员的人提供这些信息。请通过本仓库、[官方网站](https://polypay.ai/)或上方列出的官方账号核验链接与公告。
